Détectez, identifiez et testez vos manettes

InputOS est une application Windows (10 et 11, 64 bits) avec un testeur en direct, des profils officiels et des mises à jour automatiques.

Manettes compatibles

Ces manettes ont un profil officiel :

  • DualShock 4
  • DualSense (USB et Bluetooth)
  • DualSense Edge
  • Xbox Elite Series 2
  • Xbox Series S/X (USB uniquement ; les boutons Guide et Share ne sont pas disponibles)

La compatibilité peut varier selon le modèle exact et la révision matérielle. Les autres manettes vues par Windows peuvent être configurées avec « Suggérer la manette », en USB. La Nintendo Switch Pro est en développement et n'est pas prise en charge.

Suggérer une manette

Votre manette n'a pas de profil officiel ? InputOS affiche un avertissement et un bouton Suggérer la manette.

  1. Branchez la manette en USB et ouvrez InputOS.
  2. Cliquez sur « Suggérer la manette » et choisissez un modèle.
  3. Suivez le parcours : calibration des sticks, puis appui sur chaque commande.
  4. Enregistrez le profil : vous pouvez tester la manette en local en attendant un profil officiel.
  5. Si vous le souhaitez, cliquez sur « Envoyer le diagnostic » pour le transmettre aux développeurs.

L'envoi est toujours volontaire. Il crée une issue GitHub publique.

Confidentialité

InputOS n'envoie rien tant que vous ne cliquez pas sur « Envoyer le diagnostic ». Les profils enregistrés restent sur votre PC, dans Documents\InputOS\profils.

Contenu d'un diagnostic : modèle choisi, identifiants VID/PID, type de connexion, nombre de boutons/axes, calibration et association des commandes.
Jamais envoyés : nom de compte Windows, nom du périphérique donné par Windows, chemin du périphérique, identifiant privé.

Le diagnostic est transmis en HTTPS à un service Cloudflare qui crée une issue publique sur GitHub : toute personne peut la lire.
